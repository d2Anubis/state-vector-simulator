# Contributing to State Vector Simulator

Thank you for your interest in contributing! Here's how you can help.

## Getting Started

1.  **Fork** the repository on GitHub.
2.  **Clone** your fork locally:
    ```bash
    git clone https://github.com/YOUR_USERNAME/state-vector-simulator.git
    cd state-vector-simulator
    ```
3.  **Create a new branch** for your feature:
    ```bash
    git checkout -b my-new-feature
    ```

## Development

-   Install requirements (if any): `pip install -r requirements.txt`
-   Make your changes in the codebase.
-   Add your new files (e.g., `qomputing/visualisation.py`).

## Running Tests

Ensure all tests pass before submitting logic changes:
```bash
python3 -m unittest discover tests
```

## Submitting a Pull Request (PR)

1.  **Commit** your changes:
    ```bash
    git add .
    git commit -m "Add circuit drawing functionality"
    ```
2.  **Push** to your fork:
    ```bash
    git push origin my-new-feature
    ```
3.  **Open a Pull Request** on GitHub:
    -   Go to the original repository.
    -   You should see a prompt to compare & pull request.
    -   Click it, fill in the details, and submit!
